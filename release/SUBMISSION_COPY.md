## Title

Perfectly Suspicious

## Short description

Good clues. Bad alibis. A silent party game where one friend is bluffing and everyone wants the points.

## Description

Gather 3 to 8 players for a game of carefully chosen words and questionable alibis. Most players know the secret word. One suspicious player knows only its category.

Write a related clue without using the answer or an obvious giveaway. Take turns and watch each clue appear as it is submitted. Study the room and vote for the player who seems to be making it up.

The host chooses the number of cases, clue rounds in each case and time per player. Each new case brings a fresh word. Points add up across the session.

A correct personal vote earns 100 points. The suspicious player earns 200 for escaping. Keep the same group and play again with a fresh word.

Play with text and taps. No voice is needed. Try the clearly labeled guided practice to learn the rules before joining friends.

An original soundtrack and action sounds add atmosphere. Mute them in the corner settings to play quietly. Reduced motion is available too.

## Controls

On your turn, type a clue and press Enter or select Submit clue. Your accepted clue appears immediately and is final. Select another player to vote. Change your vote before the timer ends. Use Tab to move between controls and Enter or Space to activate buttons.

## Reviewer notes

The live mode requires 3 to 8 people. Guided practice uses scripted players and separate content. The live server controls roles, time, reveals, and points. There are no ads, purchases, voice features, or durable account scores in this prototype. Backend deployment and platform integration remain release gates.

The phrase quiet game describes the text based mechanic. It does not imply multiplayer works without a network connection.
